LOUD Analytics 2026 — Análise Estatística de Valorant

Sobre o projeto

O LOUD Analytics 2026 é um software desktop desenvolvido em Python como projeto acadêmico, com o objetivo de coletar, organizar e analisar dados estatísticos do cenário competitivo de Valorant, tendo como foco principal a equipe LOUD durante a temporada de 2026.

A aplicação permite visualizar o desempenho de jogadores e equipes, comparar estatísticas entre diferentes atletas, analisar mapas, agentes, composições, campeonatos e recordes históricos do Valorant Champions.

Tecnologias utilizadas

Python: linguagem principal do desenvolvimento.

Tkinter: construção da interface gráfica.

Pandas e NumPy: tratamento, organização e análise estatística dos dados.

Matplotlib: criação de gráficos e visualizações.

SQLite: armazenamento local das informações, permitindo consultas rápidas e funcionamento offline.

VLRdevAPI: biblioteca utilizada para obter informações competitivas do VLR.gg.

Requests e BeautifulSoup: coleta complementar de estatísticas históricas dos campeonatos.

Objetivo e metodologia

O projeto busca transformar dados de partidas profissionais em informações organizadas e de fácil interpretação, permitindo identificar padrões de desempenho, comparar jogadores e compreender melhor as estratégias utilizadas no cenário competitivo.

Os dados são coletados de fontes públicas, processados utilizando bibliotecas de análise de dados e armazenados em um banco SQLite. A aplicação também utiliza um sistema de cache para evitar requisições desnecessárias e melhorar o desempenho.

Além da análise da LOUD em 2026, o software permite consultar estatísticas históricas dos mundiais de Valorant de 2021 a 2026, contribuindo para comparações entre diferentes temporadas, equipes e jogadores.

Projeto desenvolvido para fins acadêmicos, sem vínculo oficial com a Riot Games, LOUD ou VLR.gg.
